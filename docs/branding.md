# Super Gacha branding

Display name: **Super Gacha**. Port creator: **alvyn16**.
Original mod: **GachaAddiction**, by **XiaoJin / Wang-Xiao-Jing**.

The icon is saved at `assets/icon.png` and bundled at
`src/main/resources/assets/gachaaddiction/icon.png`. It was created using the
built-in OpenAI image generation tool with the original icon as a style
reference. The generated PNG is used directly.

## Generation prompt

Create a NEW square Minecraft mod icon for Super Gacha. The attached original
GachaAddiction icon is ONLY an aesthetic reference: preserve its crisp
Minecraft-like pixel-art rendering, dark chocolate-brown backdrop, dramatic warm
golden glow, large diagonal slot-machine reel, bright ivory square selection
frame and bold readable pixel silhouettes. Change the actual imagery and
composition so this is clearly a distinct logo: a glowing turquoise diamond is
the selected center prize, a purple enchanted book appears in the reel above it
and an emerald below it, with small gold sparkle pixels around the reel. Keep a
chunky pixel-grid look and excellent legibility as a small mod-list icon. The
selected diamond should dominate the center in an ivory square rim, angled reel
descending from upper left toward lower right instead of copying the reference
direction. Minimal dark background side reels with faint item silhouettes, high
contrast and warm amber illumination. No text, no letters, no watermark. Deliver
the final finished icon only, filling a square canvas.

## Compatibility

The display name and JAR filename change. The `gachaaddiction` mod ID, Java
packages, asset IDs, resource-pack paths, packet IDs, config filename, and
`/gacha` command are retained for compatibility. Do not install this alongside
GachaAddiction: both deliberately use the same mod ID.
